# 목적과 검토 기준

게임을 고르면 언제 관측 지표가 얼마나 달라졌고 어떤 사건이 주변에 있었는지를 빠르게 확인한다. 수치는 출처와 실제 수집 시각으로 검증하고, 관측된 변화와 원인 가설을 분리한다.

## 화면과 사용 흐름

왼쪽 메뉴와 상단 수집 상태를 공통으로 두고, 메뉴를 선택하면 본문을 교체한다. 기본 흐름은 개요에서 변화 확인 → 게임 비교 → 지표 분석에서 구간과 근거 검토다. 소개 문구나 대형 게임 포스터를 첫 화면에 두지 않는다.

| 메뉴 | 주소 | 주요 작업 |
| --- | --- | --- |
| 개요 | `#/overview` | 현재 관측 상태, 두 게임의 핵심 수치, 최근 변화와 이벤트 확인 |
| 게임 비교 | `#/compare` | 같은 조회 기간의 최신값·관측 최고·변화·표본 수 비교 |
| 지표 분석 | `#/analysis` | 게임·지표·기간 선택, 차트와 증가 구간 확인, 관련 사건 검토, 관측 CSV 내려받기 |
| 이벤트 히스토리 | `#/events` | 게임·유형·검색어로 공식 공지와 영상 검색, 상세 내용과 원문 확인 |
| 수집 상태 | `#/collection` | 출처별 최근 시도·성공·오류, 수집 일정과 종료, 지표 정의 및 미확보 이유 확인 |

URL 직접 진입과 브라우저 뒤로 가기를 지원한다. 메뉴 이동 중 게임과 조회 기간 선택을 유지한다. 모바일에서는 메뉴를 열고 닫을 수 있으며, 넓은 표는 표 영역 안에서 스크롤한다.

가독성 기준은 밝은 회색 바탕, 흰색 패널, 파란색 선택 상태, 본문 14–15px, 숫자·시각의 고정폭 글꼴이다. 관련 없는 내부 프로젝트의 문구·자료·권한 구조를 가져오지 않는다.

## 화면에 남겨야 하는 기준

- 수치 옆에는 단위와 실제 관측 시각을 표시한다. 상세한 수집 방식과 한계 설명은 수집 상태에 모은다.
- 비교 화면은 같은 조회 범위를 사용하되, 게임별 실제 관측 범위와 표본 수가 다르면 그대로 표시한다.
- 관측 증가 행을 선택하면 차트의 해당 구간과 관련 사건을 함께 확인한다. 원인 후보의 선행·후행 관계와 근거 수준을 구분한다.
- 미확보 지표는 빈 차트나 0으로 대신하지 않는다.
- 새로고침 버튼은 게시된 JSON을 다시 읽는다. 서버 수집기를 즉시 실행하는 기능으로 표현하지 않는다.
- 과거의 검토 기록은 적용 구간과 검토 시각을 보존한다. 이후 표본에 대한 자동 분석처럼 보이지 않게 한다.

## 데이터 의미

- `null`: 확보하지 못함. `0`: 공식 API가 정상 응답한 실제 0.
- 본편 AppID와 데모 AppID는 별도 관리.
- 주기 수집 중 최대치는 ‘관측 최고 동접’. 실제 전체 피크라고 부르지 않음.
- 누락 구간을 보간하거나 과거 시계열을 생성하지 않음.
- 첫 관측 이전 성장은 판단 불가.
- 팔로워를 위시리스트로 환산하지 않음.
- 이벤트 게시 시각과 실제 발생 시각을 구분.
- 새 관측은 기존 검토 분석의 날짜를 자동 갱신하지 않음.
- 게임 장르·초기 규모가 다르므로 두 게임의 차이를 인과적 대조군 효과로 해석하지 않음.

## 분석 표현

관측 사실 / 가능한 설명 / 다른 설명 / 확인 수준 / 원문 근거를 구분한다.

- 직접 근거: 명시적인 연결 자료가 있음. 성장분 전체의 인과 입증은 아님.
- 시점상 연관: 시각이 가까우나 유입이나 기여도는 확인되지 않음.
- 판단 근거 부족: 관측이나 기준선이 부족함.

선택 기간의 인접 관측 중 양의 변화는 ‘관측 증가 구간’이다. 통계적으로 검증된 급증이나 성공·실패 판정으로 표시하지 않는다.

## 운영

정적 사이트와 JSON/CSV. GitHub Actions에서 CCU 20분, 공식 공지 3시간 목표 주기. 정확한 시각 보장은 없으며 지표별 정상 관측 후 70분 초과 시 지연을 표시한다. 아카이브 이후에는 지연 경고 대신 종료 상태를 표시한다.

행사 종료 즉시 외부 수집을 중단한다. 종료 후 유지율 분석은 제공하지 않는다. 초기 영상은 확인한 공식 자료만 포함하며 별도 영상 전수 검색은 구현 범위에 없다.

## 역할

Astra: 설계, 화면·내용 구현, 원인 표현과 최종 검토.
GPT-6.1-SOL: 게임·AppID·참가 근거·원천 지표·공지·영상 수집과 대조.
스크립트: 수집, 정규화, 누락 확인, 기록과 게시. 반복 실행에 AI 계정이나 API 키를 사용하지 않는다.
