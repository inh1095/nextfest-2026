# 초기 공개 검토

검토 시각: 2026-10-20T07:14:10Z

## 판정

로컬 구현·데이터·화면에서 초기 공개를 막을 결함을 발견하지 않았다. GitHub Actions 및 공개 Pages의 배포 성공 여부는 이 기록 작성 시점에 별도 확인 중이다. 예정된 행사 종료 시 실제 workflow 비활성화가 성공했다고 판단한 기록은 아니다.

## 목적과 내용

- 두 게임의 데모 동접과 공식 공지·초기 검증 영상의 관계를 탐색할 수 있다.
- 본편과 데모 AppID, 정상 응답 0과 미확보 `null`을 구분한다.
- 팔로워·위시리스트는 미확보이며 다른 지표로 대체하지 않는다.
- 표시하는 최고치는 관측값 중 최고다. 첫 관측 이전 이력, 관측 사이의 피크, 성장 원인을 만들어내지 않는다.
- 최초 분석 2건은 각각 최초 CCU 관측 1개에 적용된다. 새 관측이 추가돼도 검토 시각과 적용 구간을 바꾸지 않는다.
- 증가 구간 주변 사건은 구간 시작 6시간 전부터 종료 1시간 후까지 최대 3개를 표시한다. 원인으로 판정하지 않으며 범위를 화면에 공개한다.
- 자동화는 CCU와 공식 공지 수집이다. 영상 전수 조사·영상 조회수 추적·상시 AI 분석은 구현 범위가 아니다.

## 직접 확인한 검증

- 수집기 단위테스트 10개 통과. 종료 후 무요청, 재시도의 종료 경계, 중복 방지, 부분 오류, 실제 0, 공식 뉴스 CDN URL 보존을 포함한다.
- `scripts/validate.py` 통과: 당시 2게임, 관측 기록 6건, 이벤트 13건. 분석의 같은 게임 참조·적용 구간·실제 관측 참조를 검사한다.
- `node --check site/app.js` 통과.
- 데스크톱·모바일 실제 자료 스크린샷과 390px 차트 상세 이미지 확인. 이미지·숫자·결측 설명·사건 목록과 분석의 적용 구간이 읽히며 가로 잘림을 발견하지 않았다.
- 추가 브라우저 실행에서 증가 구간의 사건 버튼 → 선택 사건 상세 → 차트 시점 표시를 확인했다. 390px에서 가로 넘침과 브라우저 오류가 없었다.
- 추가 브라우저 검증은 메모리에서 응답만 교체했다. 실행 전후 운영 JSON 바이트가 동일함을 확인했다.
- 기존 `browser_smoke.py`는 데이터를 메모리에서 복제하고 브라우저 응답만 교체한다. 운영 데이터 파일을 쓰는 경로가 없고 결과 이미지는 Git 제외 대상이다.

## 운영 검토

- CCU 20분·공식 공지 3시간은 목표 주기다. 예약 실행 지연·누락을 숨기지 않는다.
- 지표와 공지의 오류·갱신 지연을 구분하고 이전 정상 자료를 보존한다.
- 열린 화면은 1분마다 상태를 다시 판단하고 5분마다 JSON을 확인한다.
- 외부 요청과 재시도 직전에 수집 종료 시각을 검사한다.
- 최종 archive 게시가 성공한 뒤에만 workflow 비활성화를 요청한다. 비활성화 실패 시 다음 예약의 재시도가 가능하다.
- 행사 후 관측·유지율 분석은 제공하지 않는다.

## 남은 외부 확인

행사 종료 시 자동 비활성화의 실제 결과는 그 시점의 실행 로그로 확인해야 한다.

## 공개 배포 검증 추가

- [초기 GitHub Actions 실행](https://github.com/inh1095/nextfest-2026/actions/runs/39385102760): monitor·publish 성공, finalize는 행사 진행 중이므로 정상적으로 건너뜀.
- [공개 사이트](https://inh1095.github.io/nextfest-2026/): 인증 없이 HTML·이미지·JSON과 화면 열람 확인, HTTPS 활성.
- 공개 URL에 대해 `tests/browser_smoke.py` 전체 통과: 게임/기간 선택, CSV, 모바일 가로 넘침, 단일 관측, 0 기준 증가율, 관측 공백, 부분 실패, 지연, 아카이브, 원문 텍스트 이스케이프.
- 원격에서 수집기가 실행되어 파일 갱신을 기록하고 정적 페이지에 반영함. 첫 실행의 CCU는 직전 로컬 관측과 같은 20분 구간이므로 중복 수집을 건너뜀.
- 공식 뉴스 4개 endpoint를 SOL이 실제 조회: 본편 2개는 각 5개 공지, 데모 2개는 정상 빈 목록. 공식 CDN 뉴스 링크는 원본 그대로 보존됨.
- 모바일 기간 필터·CSV 버튼을 최소 44×44px로 조정하고 390px 가로 넘침이 없음을 확인.
