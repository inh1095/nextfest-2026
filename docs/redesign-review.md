# 메뉴 기반 분석 도구 개편 검토

상태: 배포 전 소스·독립 브라우저·시각 검토 완료. 검토 시각: 2026-10-20T08:19:44Z. 확인된 공개 차단 결함은 없다. 실제 개편 배포 확인은 별도로 진행한다. 체크 항목은 소스 검토, 아래 직접 실행 결과 및 배포 담당이 보고한 통합 테스트 결과를 함께 반영한다.

## 변경 목적

기존 화면은 소개 문구, 차트, 사건, 해석 방법을 한 페이지에 길게 배치해 실제 비교·분석 작업을 찾기 어려웠다. 이번 개편은 목적별 메뉴와 공통 작업 영역을 제공하고, 읽는 설명보다 선택·비교·조회 동작을 앞세운다.

밝은 배경과 흰색 패널, 파란색 선택 상태, 읽기 쉬운 본문과 숫자·시각 정렬을 사용한다. 대형 포스터·슬로건·장식용 섹션 표제를 제거한다. SOC 참고 파일은 레이아웃·색상 기준만 읽으며 회사 문구, 운영 데이터, 사용자 역할과 권한 구조는 가져오지 않는다.

## 최종 정보 구조

| 메뉴 | 주소 | 사용자가 수행할 판단과 작업 |
| --- | --- | --- |
| 개요 | `#/overview` | 두 게임의 최신 관측과 수집 상태 확인, 최근 변화 또는 사건에서 상세 화면으로 이동 |
| 게임 비교 | `#/compare` | 같은 조회 기간의 최신 관측·관측 최고·변화량·표본 수 비교, 실제 관측 범위 차이 확인 |
| 지표 분석 | `#/analysis` | 게임·지표·기간 선택, 차트와 증가 구간 확인, 선택 구간의 주변 사건·검토 근거 확인, CSV 저장 |
| 이벤트 히스토리 | `#/events` | 게임·종류·검색어·KST 날짜로 사건 조회, 원문과 게시·발생 시각 확인 |
| 수집 상태 | `#/collection` | 출처별 수집 시도·상태·오류 확인, 주기·종료 일정·지표 정의·미확보 사유 확인 |

상세 설명은 수집 상태 메뉴에 모으되, 수치의 단위·조회 기간·실제 관측 시각·오류 상태는 해당 수치 옆에 남긴다.

## 기능과 지표 검토 체크리스트

### 공통 이동과 상태

- [x] 다섯 메뉴가 본문을 교체하고 현재 위치를 명확히 표시한다.
- [x] hash 직접 진입, 새로고침, 브라우저 뒤로 가기가 동작한다.
- [x] 메뉴를 오가도 게임·조회 기간 선택을 유지한다.
- [x] 데이터 새로고침은 게시된 JSON 재조회이며 즉시 원천 수집으로 설명하지 않는다.
- [x] 데이터 재조회 실패 시 기존 자료를 유지하고 실패 상태를 표시한다.
- [x] 모바일 메뉴 열기·닫기·Escape 동작과 키보드 접근을 확인한다.

### 개요와 비교

- [x] 최신 변화는 마지막 정상 인접 관측끼리 비교하고 기준 시각을 표시한다.
- [x] 실패 관측이나 허용 간격을 넘은 공백을 건너뛰어 최신 증가를 만들지 않는다.
- [x] 비교는 동일한 조회 기간을 사용하고 게임별 실제 관측 범위·횟수를 표시한다.
- [x] 기간 밖 관측이 선택 기간의 최고값·변화량에 섞이지 않는다.
- [x] 실제 0과 미확보를 구분하며 성패 점수·승자·인과적 대조군으로 해석하지 않는다.

### 지표 분석

- [x] 단일 관측에서 추세·변화율·증가 구간을 생성하지 않는다.
- [x] 증가표는 시작·끝 시각과 값, 절대 증가, 계산 가능한 증가율, 실제 시간 간격을 보여준다.
- [x] 기준값 0의 증가율은 `—` 등으로 표시하며 `Infinity`나 임의의 비율을 만들지 않는다.
- [x] 수집 실패와 장시간 결측은 선과 증가 계산을 끊는다.
- [x] 증가 행 선택이 차트 선택 구간 및 근거 패널에 반영된다.
- [x] 주변 사건의 검색 범위를 표시하고 선행·구간 내·후행 관계를 구분한다.
- [x] 사건의 시점이 가깝다는 사실을 원인 입증으로 표시하지 않는다.
- [x] 기존 검토는 적용 구간·검토 시각을 보존하며 새 관측에 자동 재적용하지 않는다.
- [x] 팔로워 미확보는 짧은 사유로 표현하며 0이나 반복적인 빈 대형 차트를 만들지 않는다.
- [x] CSV의 게임·기간·값·결측 상태가 현재 조회와 일치한다.

### 이벤트와 수집 상태

- [x] 게임·종류·검색·KST 날짜 필터를 조합할 수 있고 결과 없음 상태가 명확하다.
- [x] 날짜 경계는 KST 기준이며 게시 시각과 사건 발생 시각을 혼동하지 않는다.
- [x] 확인하지 못한 시각을 임의로 생성하거나 검색 결과 0을 활동 없음으로 해석하지 않는다.
- [x] 제목·요약은 텍스트로 처리하고 원문 링크가 동작한다.
- [x] CCU와 공식 공지의 주기 차이를 반영해 오류·지연 상태를 표시한다.
- [x] 오류가 있어도 기존 정상 관측과 사건을 지우지 않는다.
- [x] 종료 시각 이후 종료 상태를 표시하며 행사 후 관측을 계획한 것처럼 표현하지 않는다.

### 가독성과 보존

- [x] 1440px 데스크톱에서 주요 표·필터·상태가 겹치거나 잘리지 않는다.
- [x] 390px 모바일에서 본문 가로 넘침 없이 표 영역만 필요한 스크롤을 제공한다.
- [x] 본문·표·축·오류 상태의 글자 크기와 명암을 실제 화면으로 확인한다.
- [x] 긴 설명·중복 안내가 분석 작업 영역을 밀어내지 않는다.
- [x] 운영 관측 JSON·CSV·초기 근거·고정 분석이 보존된다.
- [x] 테스트용 자료는 브라우저 메모리에만 주입하고 운영 파일을 변경하지 않는다.
- [x] 기존 수집 자동화와 종료 로직을 이번 화면 개편으로 변경하지 않는다.

## 검증 계획과 기록 범위

`tests/browser_smoke.py`의 메모리 fixture와 UI 선택자를 기준으로 메뉴 이동, 필터 유지, CSV, 단일 관측, 0 기준값, 결측·실패, 이벤트 필터, 종료 상태와 텍스트 처리를 검사한다.

독립 검토에서는 기간 밖 고점 배제, 최신 변화의 기준, KST 날짜 경계, 구간·사건 연결과 검토 적용 범위를 추가 확인한다. 실행한 명령·시나리오·결과만 아래에 기록한다.

## 직접 실행한 독립 검증 결과

브라우저 시각을 고정하고 가상 데이터는 응답 메모리에서만 사용했다. 운영 JSON을 쓰지 않았다.

1. **선택 기간 밖 최고값 제외:** 24시간 밖의 9,999를 비교 최고값에서 제외하고 기간 안 최고값 20을 표시했다.
2. **최신 변화 기준:** 10 → 20 → 17의 관측에서 최근 변화는 -3으로 표시됐다. 첫 관측 대비 +7을 최신 변화로 쓰지 않았다.
3. **마지막 수집 실패:** 마지막에 오류 관측을 추가하면 이전 정상 증가를 재사용하지 않고 비교 가능한 인접 관측이 없다고 표시했다.
4. **KST 날짜 경계:** UTC 14:59:59와 15:00:00의 사건을 KST 전날 23:59:59와 당일 00:00:00으로 구분해 날짜 필터를 적용했다.
5. **검토 적용 범위:** 시작 시점 하나만 검토한 과거 분석을 이후 증가 구간의 근거로 표시하지 않았다.
6. **구간과 사건 연결:** 증가 구간의 차트 음영과 선택 사건의 점선이 표시됐고, 구간 이후의 사건은 후행으로 구분됐다.
7. **명시 사건 링크:** 기존 게임·종류·검색 필터와 6시간 조회 범위 밖의 사건을 직접 열어도 요청한 사건의 상세를 유지했다. 필터 밖임을 안내하고 기존 필터를 보존했다.
8. **새로고침 실패:** JSON 재조회가 503으로 실패해도 기존 상세를 유지하고 실패 안내를 표시했다.
9. **실제 자료와 화면:** 개요·분석·이력 1440px, 분석·비교 390px에서 JavaScript 오류와 본문 가로 넘침이 없었다. 수치·단위·표·차트·필터가 읽히는 것을 이미지로 확인했다.
10. **운영 자료 보존:** 독립 테스트 전후 운영 observations.json 바이트가 동일했다.

## 통합 검증 보고와 한계

배포 담당은 신규 `tests/browser_smoke.py`의 12개 시나리오 묶음 전체 통과, 수집기 단위테스트 10개 통과, 데이터 검증 2게임·관측 8건·이벤트 13건 통과를 보고했다. 독립 실행 결과와 혼동하지 않도록 여기 별도로 기록한다.

현재 사건 자료에는 시간 단위 정밀도(`hour`)만 가진 사건이 없다. 그런 자료가 추가될 경우 분 단위 경계에서 선행·후행을 단정하지 않도록 정밀도에 따른 표시를 다시 검토해야 한다. 현재 자료의 분석이나 공개를 막는 문제로 분류하지 않았다.

이번 문서는 로컬 소스와 화면을 검토한 기록이다. 공개 URL의 개편 반영, GitHub Actions 실행 결과, 행사 종료 시 실제 자동 중단은 이 문서의 통과 판정에 포함하지 않는다.
